01 Tailwind CSS v4 Architecture & Semantic Layers

How HeroUI tokens map to Tailwind v4 custom theme properties.

Surface & Content Layer Hierarchy

HeroUI establishes clear visual hierarchy using layered surface tokens: bg-background (0), bg-content1 (Card base), bg-content2 (Subtle wells & table headers), bg-content3 (Hover states), and bg-content4 (Active borders).

bg-background Level 0 (Canvas)
bg-content1 Level 1 (Cards & Modals)
bg-content2 Level 2 (Wells & Inputs)
bg-content3 Level 3 (Hover States)

Tailwind v4 @theme Declaration

@theme {
  --color-background: var(--heroui-bg);
  --color-foreground: var(--heroui-fg);
  --color-content1: var(--heroui-content1);
  --color-content2: var(--heroui-content2);
  --color-primary: var(--heroui-primary);
  --color-secondary: var(--heroui-secondary);
  --color-success: #17c964;
  --color-warning: #f5a524;
  --color-danger: #f31260;
  --radius-heroui-2xl: 20px;
}
